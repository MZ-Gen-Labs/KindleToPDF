# Kindle自動化アプリ要件定義書

## 概要
Kindle for PCのページめくり、画面キャプチャ、PDF作成を自動化するWindowsアプリケーション。

## 対象アプリケーション
- **名称**: Kindle for PC
- **プラットフォーム**: Windows

## 開発環境・言語選定
- **言語**: C#
- **フレームワーク**: .NET 8.0 (Windows Forms)
- **選定理由**:
    - **Windows APIとの親和性**: ウィンドウハンドルの取得やバックグラウンドでのキー送信など、Win32 API (User32.dll) を利用した制御が容易かつ確実に行えるため。
    - **GUI開発の効率性**: Visual Studioのフォームデザイナーを使用することで、設定画面などのUIを迅速に構築できるため。
    - **ライブラリの充実**: 画面キャプチャ(System.Drawing)やPDF作成(PdfSharp/QuestPDF)に必要なライブラリが豊富で、安定しているため。
- **主要ライブラリ候補**:
    - PDF作成: PdfSharp, QuestPDF
    - 画像処理: System.Drawing.Common


## 機能要件

### 0. [NEW] キャプチャモード選択
アプリケーションは2つのキャプチャモードをサポートする：

#### 0.1 連続自動キャプチャモード（既存）
- 自動的にページをめくりながら連続してキャプチャ
- ページ数指定または最終ページまで自動実行
- 既存の機能をそのまま維持

#### 0.2 手動選択キャプチャモード（新規）
- **目的**: 必要なページだけを選択的にキャプチャし、PDFを作成する
- **操作フロー**:
  1. ユーザーが手動でKindleのページを移動
  2. 必要なページで「キャプチャ」ボタンをクリック
  3. キャプチャした画像を一時保存（リストに追加）
  4. 必要なページをすべてキャプチャ後、「PDF作成」ボタンで結合
- **UI要素**:
  - **「キャプチャ」ボタン**: 現在表示中のページをキャプチャしてリストに追加
  - **キャプチャ数表示**: 現在何枚キャプチャ済みかを表示（例: "Captured: 5 pages"）
  - **「最後を削除」ボタン**: 最後にキャプチャした画像を削除（間違えた時用）
  - **「すべてクリア」ボタン**: すべてのキャプチャ画像をクリア
  - **「PDF作成」ボタン**: キャプチャした画像からPDFを生成
- **動作**:
  - キャプチャボタンを押すと、現在のKindleウィンドウをキャプチャ
  - クロップ設定が有効な場合は適用
  - キャプチャした画像は一時フォルダに保存し、リストに追加
  - PDF作成時は、キャプチャした順序でページを結合
- **UI制御**:
  - 手動モード選択時は、自動モード専用のコントロール（Interval, Page Count, Auto-detect等）を無効化
  - 自動モード選択時は、手動モード専用のコントロールを無効化

### 1. ページナビゲーション (ページめくり)
- キーボード操作をシミュレートして自動でページをめくる。
- **使用キー**: 右矢印キー または PageDownキー。
- **間隔**: 
    - 固定待機時間（既存）。
    - **[MODIFY] 自動判別**: 
        - ページめくり後、**0.1秒間隔**で画面比較を行う。
        - **2回連続**で画面変化がない（安定した）場合、ページ遷移完了とみなして次へ進む（**デフォルトON**）。
        - **タイムアウト**: 最大4秒間（0.1秒×40回）待機しても変化がない場合は、ページめくり失敗とみなして警告ログを出力し、次へ進む。
        - **UI制御**: ONの場合、固定待機時間（Interval）の設定は無効化（グレーアウト）される。
    - **[NEW] 最終ページ判定**:
    - 指定ページ数での停止に加え、**「最終ページまで」**モードを追加。
    - ページめくり操作を行っても画面変化がない場合を最終ページと判断して停止する（**デフォルトON**）。
    - **UI制御**: ONの場合、ページ数（Page Count）の設定は無効化（グレーアウト）される。
- **[NEW] ページ送り方向**:
    - **右送り (Right-to-Left)**: 日本語の縦書き書籍など（デフォルト）。キー: `Left Arrow` (Kindleの挙動に合わせる: 左キーで次へ) ※要確認
        - *補足*: Kindle for PCでは、右開き（縦書き）の場合、キーボードの「←（左矢印）」または「PageDown」で次のページに進むのが一般的か？
        - *修正*: 一般的なKindle操作:
            - 右開き（縦書き）: `←` (Left) で次へ
            - 左開き（横書き）: `→` (Right) で次へ
    - **左送り (Left-to-Right)**: 英語の書籍など。キー: `Right Arrow`
    - **UI**: コンボボックスまたはラジオボタンで選択可能にする。
    - **設定保存**: 次回起動時に選択状態を復元する。

### 2. 画面キャプチャ
- Kindleウィンドウの領域をキャプチャする。
- **形式**: 画像ファイル（PNG/JPG等）として一時保存する。
- **範囲**: 全画面、または特定のウィンドウ範囲（Kindleウィンドウの検出が必要）。
- **[NEW] 枠外カット（トリミング）**:
    - キャプチャ画像の不要な枠外（余白など）をカットする機能。
    - **指定方法**: 画面上に**4本の線（上下左右）**を表示し、マウスでドラッグしてカット範囲を指定できるUIを提供する。

### 3. PDF作成
- キャプチャした複数の画像を1つのPDFファイルに結合する。
- **出力**: ユーザー指定のファイル名、またはタイムスタンプ付きの自動生成名。

#### 3.1 書籍タイトル自動取得
- Kindle for PCのウィンドウタイトルから書籍名を取得する。
- ウィンドウタイトル形式: `"Kindle for PC [端末名] - [書籍名]"`
- 最初の `" - "` (スペース-ハイフン-スペース) 以降の部分を書籍名として抽出する。
- 取得した書籍名をPDFファイル名のデフォルト値として使用する。
- 書籍名に使用できない文字（`\ / : * ? " < > |`）はアンダースコア `_` に置換する。
- **更新ボタン**: 「Output PDF」フィールドの横に「更新」ボタンを配置し、いつでも手動で書籍タイトルを再取得できるようにする。
- **起動時の動作**: アプリ起動時にKindleウィンドウが開いている場合、自動的に書籍タイトルを取得して表示する。取得できない場合は `output.pdf` を表示する。

#### 3.2 ファイル名生成ロジック
- **デフォルト**: `[書籍名].pdf`
- **同名ファイルの処理**:
    - 既に同名のファイルが存在する場合の挙動を選択可能にする。
    - **上書き (Overwrite)**: 既存のファイルを上書きする。
    - **連番作成 (Sequential)** (デフォルト): 別名で保存する。以下のパターンを選択可能。
        - **数字 (Number)** (デフォルト):
            - 形式: `[書籍名]_[数値].pdf`
            - 設定: 開始番号 (Start Number, デフォルト: 1), 桁数 (Digits/Padding, デフォルト: 3桁、例: 001)
        - **アルファベット (Alphabet)**:
            - 形式: `[書籍名]_[文字].pdf`
            - 設定: 開始文字 (Start Char, デフォルト: a)
        - **日時 (Date/Time)**:
            - 形式: `[書籍名]_[日時].pdf`
            - 設定: 書式 (Format, デフォルト: `yyyyMMdd`)
                - `yyyyMMdd` (例: 20231124)
                - `yyyyMMdd_HHmmss` (例: 20231124_123456)
                - `yyyy-MM-dd` (例: 2023-11-24)
                - `yyyy-MM-dd_HH-mm-ss` (例: 2023-11-24_12-34-56)
                - カスタム書式も入力可能
- **UI**:
    - 「Output PDF」欄の近くに「File Name Options」ボタンを配置。
    - **Mode**: RadioButton [Overwrite, Sequential]
    - **Sequential Type**: ComboBox [Number, Alphabet, DateTime] (Sequential選択時のみ有効)
    - **Type Specific Settings**:
        - Number: NumericUpDown (Start), NumericUpDown (Digits)
        - Alphabet: TextBox (Start Char)
        - DateTime: ComboBox (Format Patterns) - カスタム入力可能
- **設定保存**:
    - 命名ルールの設定も `settings.json` に保存・復元する。

#### 3.3 PDF圧縮・画質設定
- **PDF圧縮**: 
    - PDFドキュメントの圧縮を有効化（`CompressContentStreams = true`）
    - 最高圧縮モード使用（`FlateEncodeMode = BestCompression`）
- **画像カラーモード**: 以下のモードから選択可能（デフォルト: Grayscale）
    - **Monochrome (白黒2値)**: 
        - 最小ファイルサイズ
        - 1ビット/ピクセル
        - 閾値128でグレースケール変換後に2値化
        - PNG形式で保存
    - **Grayscale (グレースケール)** (デフォルト):
        - 小さいファイルサイズ
        - 8ビット/ピクセル (256階調)
        - PNG形式で保存
    - **Indexed256 (インデックスカラー256色)**:
        - 中程度のファイルサイズ
        - 8ビット/ピクセル (256色パレット)
        - ハーフトーンパレット使用
        - PNG形式で保存
    - **HighColor (高色)**:
        - 中程度のファイルサイズ
        - 16ビット/ピクセル (RGB565)
        - JPEG形式で保存（品質設定可能）
    - **FullColor (フルカラー)**:
        - 最大ファイルサイズ
        - 24ビット/ピクセル
        - JPEG形式で保存（品質設定可能）
- **JPEG品質設定**:
    - HighColorまたはFullColor選択時のみ有効
    - 範囲: 60-100 (デフォルト: 80)
    - TrackBarで調整可能
    - 設定値をリアルタイム表示
- **UI**:
    - **Color Mode**: ComboBox [Monochrome, Grayscale, Indexed256, HighColor, FullColor]
    - **JPEG Quality**: TrackBar (60-100) + 数値表示ラベル
        - HighColor/FullColor選択時のみ表示
- **設定保存**:
    - カラーモードとJPEG品質設定を `settings.json` に保存・復元する。

#### 3.4 処理制御
- **[NEW] 最終ページ検知による自動停止**。
- **[MODIFY] DELETEキーによる一時停止**: 
    - キャプチャ実行中にDELETEキーを押すと、**プログラムを中断（ポーズ）してウィンドウを表示**する（PDF作成は行わない）。
    - ポーズ中、再度「開始（または再開）」ボタンを押すと、非表示になって続きから処理を再開する。
    - ポーズ中に「停止」ボタンを押すと、終了してPDFを作成する。
- **[NEW] 中止 (Abort)**:
    - PDFを作成せずに処理を終了し、初期状態に戻るボタンを追加する。
    - ボタン名: "Abort" (または "Cancel")
    - 動作: 取得した画像を破棄し、PDF生成を行わずに待機状態に戻る。

### 5. [NEW] UI/UX
- **最前面表示**: アプリケーションウィンドウを常に他のウィンドウより手前に表示する設定（デフォルトON）。
- **自動非表示**: キャプチャ開始時にアプリを自動的に隠し、キャプチャ対象（Kindle）の邪魔にならないようにする。
- **タブ化UI**: 機能を4つのタブに整理（Home, Settings, Crop, Log）して、UIをより使いやすく整理。


### 6. [NEW] マージンカット（クロップエリア指定）
- **目的**: キャプチャ画像から不要な部分（ウィンドウの枠など）を除外する。
- **UI**: 「Set Crop Area」ボタンをクリックすると、全画面オーバーレイが表示される。
- **操作方法1: ビジュアル指定**:
        - Top: `0` (常に0から開始)
        - Right: スクリーンの幅（例: `1920`）
        - Bottom: スクリーンの高さ（例: `1080`）
- **適用**: 確定後、以降のキャプチャでは指定した範囲のみが保存される。

### 7. [NEW] 手動ナビゲーション（動作確認用）
- **目的**: ページ送り方向の設定が正しいか確認するため、および開始位置への移動補助。
- **UI**: メイン画面に以下のボタンを追加（ページ方向設定の下あたり）。
    - `[<< Top]`: 最初のページへ移動
        - **実装詳細**: `Ctrl+G` を送信 -> 0.5秒待機 -> `1` を入力 -> `Enter` を送信。
        - (以前の `VK_HOME` 送信はKindle for PCで動作しなかったため変更)
    - `[< Prev]`: 前のページへ移動
    - `[Next >]`: 次のページへ移動
    - **[NEW] [>> Bottom]**: 最終ページへ移動
        - **実装詳細**: `Ctrl+G` でダイアログを開き、**UI Automation** を使用してダイアログ内の総ページ数（例: "/ 136"）を読み取る。その後、取得したページ数を入力して移動する。
        - **エラー処理**: 取得に失敗した場合はログにエラーを出力し、処理を中断する。
    - **[NEW] [Full Screen]**: フルスクリーン表示の切り替え
        - **動作**: `F11` キーを `PostMessage` API で送信して、Kindleのフルスクリーンモードと通常モードを切り替える。
- **動作**: 現在の「ページ送り方向」設定（右送り/左送り）に従って、適切なキーを送信する。
    - **右送り (JP)**: Prev=`→`, Next=`←`
    - **左送り (EN)**: Prev=`←`, Next=`→`

### 8. [NEW] Kindleウィンドウ検出
- **目的**: Kindle for PCの正しいメインウィンドウを特定して操作する。
- **背景**: 
    - Kindle for PCは複数のウィンドウ（7つ程度）を持つマルチウィンドウアプリケーション
    - `Process.MainWindowHandle` は内部で使用される隠しウィンドウ（Internet Explorer_Hidden）を返す
    - 実際のメインウィンドウは別のウィンドウハンドルとして存在する
- **実装方法**:
    - `EnumWindows` APIを使用してKindleプロセスに属するすべてのウィンドウを列挙
    - 各ウィンドウのクラス名（`GetClassName`）とタイトル（`GetWindowText`）を取得
    - クラス名が `Qt5QWindowIcon` で、タイトルに "for PC" が含まれるウィンドウをメインウィンドウとして特定
- **メインウィンドウの特徴**:
    - ClassName: `Qt5QWindowIcon`
    - Title: "Kindle for PC msi" または "Kindle for PC [デバイス名] - [書籍名]"
    - 最小化時: `IsIconic: True`, Bounds: `{X=-32000, Y=-32000, ...}`
    - 通常時: `IsIconic: False`, 通常の画面座標
- **使用API**:
    - `EnumWindows`: すべてのトップレベルウィンドウを列挙
    - `GetWindowThreadProcessId`: ウィンドウが属するプロセスIDを取得
    - `GetClassName`: ウィンドウのクラス名を取得
    - `GetWindowText`: ウィンドウのタイトルを取得
- **詳細**: `docs/KINDLE_WINDOW_DETECTION.md` を参照

### 9. [NEW] ウィンドウ操作（最小化・復元・最大化）
- **最小化**: `ShowWindow(hWnd, SW_MINIMIZE)` でKindleウィンドウを最小化
- **復元**: 
    - `IsIconic` で最小化状態を確認
    - 最小化されている場合は `ShowWindow(hWnd, SW_RESTORE)` で復元
    - 復元完了を待機してから次の操作へ
- **最大化**:
    - 最小化されている場合は先に復元
    - `ShowWindowAsync(hWnd, SW_MAXIMIZE)` で最大化
    - `SetForegroundWindow` で前面に表示
- **注意事項**:
    - 最小化状態から直接 `SW_MAXIMIZE` を実行するとハングする可能性がある
    - 必ず復元してから最大化する手順を踏む
    - 正しいウィンドウハンドルを使用することが重要

## 非機能要件
- **パフォーマンス**: ページ飛ばしを防ぐため、キャプチャ処理の遅延を最小限にする。
- **ユーザビリティ**: 設定（間隔、ページ数、出力パス）のためのシンプルなGUI。
