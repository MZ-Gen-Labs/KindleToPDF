# Kindle自動化アプリ要件定義書

## 概要
Kindle for PCのページめくり、画面キャプチャ、PDF作成を自動化するWindowsアプリケーション。

## 対象アプリケーション
- **名称**: Kindle for PC
- **プラットフォーム**: Windows

## 開発環境・言語選定
- **言語**: C#
- **フレームワーク**: .NET 8.0 (Windows Forms)
- **選定理由**:
    - **Windows APIとの親和性**: ウィンドウハンドルの取得やバックグラウンドでのキー送信など、Win32 API (User32.dll) を利用した制御が容易かつ確実に行えるため。
    - **GUI開発の効率性**: Visual Studioのフォームデザイナーを使用することで、設定画面などのUIを迅速に構築できるため。
    - **ライブラリの充実**: 画面キャプチャ(System.Drawing)やPDF作成(PdfSharp/QuestPDF)に必要なライブラリが豊富で、安定しているため。
- **主要ライブラリ候補**:
    - PDF作成: PdfSharp, QuestPDF
    - 画像処理: System.Drawing.Common


## 機能要件

### 1. ページナビゲーション (ページめくり)
- キーボード操作をシミュレートして自動でページをめくる。
- **使用キー**: 右矢印キー または PageDownキー。
- **間隔**: 
    - 固定待機時間（既存）。
    - **[MODIFY] 自動判別**: 
        - ページめくり後、**0.1秒間隔**で画面比較を行う。
        - **2回連続**で画面変化がない（安定した）場合、ページ遷移完了とみなして次へ進む（**デフォルトON**）。
- **[NEW] 最終ページ判定**:
    - 指定ページ数での停止に加え、**「最終ページまで」**モードを追加。
    - ページめくり操作を行っても画面変化がない場合を最終ページと判断して停止する（**デフォルトON**）。

### 2. 画面キャプチャ
- Kindleウィンドウの領域をキャプチャする。
- **形式**: 画像ファイル（PNG/JPG等）として一時保存する。
- **範囲**: 全画面、または特定のウィンドウ範囲（Kindleウィンドウの検出が必要）。
- **[NEW] 枠外カット（トリミング）**:
    - キャプチャ画像の不要な枠外（余白など）をカットする機能。
    - **指定方法**: 画面上に**4本の線（上下左右）**を表示し、マウスでドラッグしてカット範囲を指定できるUIを提供する。

### 3. PDF作成
- キャプチャした複数の画像を1つのPDFファイルに結合する。
- **出力**: ユーザー指定のファイル名、またはタイムスタンプ付きの自動生成名。
- **[NEW] 書籍タイトル自動取得**:
    - Kindle for PCのウィンドウタイトルから書籍名を取得する。
    - ウィンドウタイトル形式: `"Kindle for PC [端末名] - [書籍名]"`
    - 最初の `" - "` (スペース-ハイフン-スペース) 以降の部分を書籍名として抽出する。
    - 取得した書籍名をPDFファイル名のデフォルト値として使用する。
    - 書籍名に使用できない文字（`\ / : * ? " < > |`）はアンダースコア `_` に置換する。
    - **更新ボタン**: 「Output PDF」フィールドの横に「更新」ボタンを配置し、いつでも手動で書籍タイトルを再取得できるようにする。
    - **起動時の動作**: アプリ起動時にKindleウィンドウが開いている場合、自動的に書籍タイトルを取得して表示する。取得できない場合は `output.pdf` を表示する。
- **[NEW] 設定保存**:
    - アプリ終了時（または設定変更時）に現在の設定値を `settings.json` に保存する。
    - アプリ起動時に `settings.json` があれば読み込んで復元する。
    - **保存項目**: Interval, Page Count, Auto-detect, Stop at Last Page, Always on Top, DPI, Crop Area.
    - **保存しない項目**: Output PDF (書籍ごとに異なるため、毎回自動取得する)
- **[NEW] 中断時の動作**: 「停止」ボタン押下時も、それまでにキャプチャした画像でPDFを作成してから終了する。
- **[NEW] 解像度指定**:
    - PDF生成時の解像度(DPI)を指定可能にする。
    - デフォルト: システムのDPI設定を取得して表示。
    - 選択肢: 300dpi, 450dpi, 600dpi 等。

### 4. 自動化制御
- **開始**: プロセスを開始するボタン。
- **停止**:
    - 手動停止ボタン/ホットキー（**PDF作成を実行して終了**）。
    - 指定ページ数到達後の自動停止。
    - **[NEW] 最終ページ検知による自動停止**。
    - **[MODIFY] DELETEキーによる一時停止**: 
        - キャプチャ実行中にDELETEキーを押すと、**プログラムを中断（ポーズ）してウィンドウを表示**する（PDF作成は行わない）。
        - ポーズ中、再度「開始（または再開）」ボタンを押すと、非表示になって続きから処理を再開する。
        - ポーズ中に「停止」ボタンを押すと、終了してPDFを作成する。

### 5. [NEW] UI/UX
- **最前面表示**: アプリケーションウィンドウを常に他のウィンドウより手前に表示する設定（デフォルトON）。
- **自動非表示**: キャプチャ開始時にアプリを自動的に隠し、キャプチャ対象（Kindle）の邪魔にならないようにする。

### 6. [NEW] マージンカット（クロップエリア指定）
- **目的**: キャプチャ画像から不要な部分（ウィンドウの枠など）を除外する。
- **UI**: 「Set Crop Area」ボタンをクリックすると、全画面オーバーレイが表示される。
- **操作方法1: ビジュアル指定**:
    - 4本の赤いライン（上下左右）が表示される。
    - **初回表示時**: デフォルトで画面の10%マージンの位置にラインが表示される。
    - **2回目以降**: 前回保存したクロップエリアの位置にラインが表示される（設定ファイルから復元）。
    - ラインをドラッグして、キャプチャしたい範囲を指定する。
    - ENTERキーで確定、ESCキーでキャンセル。
- **操作方法2: 数値入力**:
    - メインウィンドウに上下左右のマージン値を入力するテキストボックスを配置する。
    - 単位: ピクセル (px)
    - 入力項目: Left, Top, Right, Bottom
    - 数値を入力すると、その値が即座にクロップエリアとして適用される。
    - ビジュアル指定と数値入力は連動し、どちらで変更しても両方に反映される。
    - **ガイドライン表示**: 
        - メインウィンドウ表示中、常にクロップエリアのガイドライン（4本の赤いライン）を画面上に表示する。
        - 数値入力でクロップエリアを変更すると、ガイドラインがリアルタイムで更新される。
        - ガイドラインは半透明のオーバーレイとして表示され、他のウィンドウの操作を妨げない。
    - **上限値表示**: 各入力欄の下に、プライマリスクリーンの解像度に基づく上限値を数値のみで表示する。
        - Left: `0` (常に0から開始)
        - Top: `0` (常に0から開始)
        - Right: スクリーンの幅（例: `1920`）
        - Bottom: スクリーンの高さ（例: `1080`）
- **適用**: 確定後、以降のキャプチャでは指定した範囲のみが保存される。

## 非機能要件
- **パフォーマンス**: ページ飛ばしを防ぐため、キャプチャ処理の遅延を最小限にする。
- **ユーザビリティ**: 設定（間隔、ページ数、出力パス）のためのシンプルなGUI。
