# KindleToPDF

Kindle for PC のページめくり、画面キャプチャ、PDF作成を自動化するWindowsアプリケーションです。

## 概要

このツールは、Windows版 Kindle for PC で開いている書籍を自動的にページめくりし、スクリーンショットを撮影して、最終的に一つのPDFファイルとして保存します。
自炊（電子書籍のPDF化）作業を効率化するために開発されました。

## 主な機能

*   **自動ページめくり**: キーボード操作（右矢印キー/PageDown）をシミュレートして自動でページをめくります。
*   **スマートなページ遷移検知**: 画面の変化を検知して、ページめくりが完了したことを確認してから次へ進みます。
*   **自動停止**: 最終ページ（画面変化なし）を検知して自動的に停止します。
*   **PDF作成**: キャプチャした画像を結合してPDFを出力します。
*   **書籍タイトル自動取得**: Kindleのウィンドウタイトルから書籍名を取得し、PDFのファイル名として自動設定します。
*   **クロップ（トリミング）機能**: キャプチャ画像の不要な余白（ウィンドウ枠など）をカットできます。ビジュアル操作または数値入力で指定可能です。
*   **設定保存**: 次回起動時に設定（間隔、クロップ範囲など）を復元します。

## 動作環境

*   **OS**: Windows 10 / 11
*   **必須ランタイム**: .NET 10.0 Desktop Runtime
*   **対象アプリ**: Kindle for PC

## 開発環境

*   Visual Studio 2022 以降
*   .NET 10.0 SDK
*   **言語**: C# (Windows Forms)
*   **使用ライブラリ**:
    *   PDFsharp (PDF作成)

## セットアップと使用方法

1.  **準備**:
    *   Kindle for PC をインストールし、ログインしておきます。
    *   PDF化したい書籍をKindle for PCで開き、全画面表示または読みやすいサイズに調整します。

2.  **ビルド/実行**:
    *   このリポジトリをクローンします。
    *   `src/KindleToPDF.csproj` を Visual Studio 等で開き、ビルド・実行します。

3.  **操作**:
    *   **Output PDF**: 保存するPDFファイル名（自動取得されますが変更可能）。
    *   **Interval**: ページめくりの待機時間（ミリ秒）。自動検知(Auto-detect)がONの場合は補助的な役割になります。
    *   **Set Crop Area**: 必要に応じてキャプチャ範囲を調整します。
    *   **Start**: 自動化を開始します。開始後、Kindleウィンドウがアクティブになります。
    *   **Stop**: 途中停止します（そこまでの画像でPDFが作成されます）。
